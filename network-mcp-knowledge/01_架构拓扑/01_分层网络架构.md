# 全网分层网络架构
## 1. 分层模型（标准三层架构）
1. 核心层：核心汇聚交换机、USG防火墙、K8s集群网关
2. 汇聚层：楼栋汇聚交换机、GRE隧道网关
3. 接入层：工位接入交换机、无线AP接入设备
4. 业务容器层：K8s节点、Docker业务容器、Ingress负载均衡

## 2. 文字链路拓扑
终端PC → 接入交换机 → 汇聚交换机 → 核心交换机 → USG防火墙 → 外网/服务器区
K8s Pod → Calico网络 → OpenELB EIP → 核心交换机 → 办公接入区

## 3. 跨区域互联链路
总部 <-> 分中心：GRE隧道加密互联，OSPF动态路由互通
办公区 <-> 服务器区：防火墙域间策略隔离访问

## 4. 网络隔离规则
- 办公终端：禁止直接访问K8s集群后端Pod，仅允许访问EIP负载均衡地址
- 服务器区：仅运维管理机可ssh登录容器节点
- AD域控独立网段，仅办公终端可完成域认证
