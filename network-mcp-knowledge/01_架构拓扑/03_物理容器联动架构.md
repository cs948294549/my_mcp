# 物理网络与K8s/Docker容器互通架构
## 1. K8s网络模型
- CNI插件：Calico BGP模式，Pod网段独立三层可达
- 负载均衡：OpenELB Layer2模式分配EIP，同网段广播ARP对外暴露服务
- Ingress-Nginx：集群内部七层反向代理，对接后端业务Pod

## 2. Docker单机容器网络
- 默认bridge网络，容器DNS指向127.0.0.11
- 如需解析内网私有域名，宿主机部署dnsmasq，容器DNS上游转发宿主机DNS
- 容器无法直接读取宿主机hosts文件，统一通过dnsmasq管理内网域名映射

## 3. 物理互通逻辑
1. K8s EIP地址段与办公接入网段同二层广播域，核心交换机转发EIP流量
2. Calico IPPool做SNAT控制，避免同网段EIP回程源IP被转换导致无法访问
3. 容器访问物理服务器：经过网关三层转发，防火墙策略放行对应端口

## 4. 互通故障关键点
1. OpenELB ARP回复异常 fe:ff:ff:ff:ff:ff：二层广播/Calico SNAT冲突
2. 容器NXDOMAIN域名解析：Docker DNS未正确转发宿主机dnsmasq
3. EIP同网段无法ping通：Calico出站SNAT篡改源IP，回程流量异常
